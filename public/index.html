For developers / 02

Use it without the browser.

Use the same GitHub lookups as JSON or MCP tools. They run with this site on Cloudflare Pages.

Profiles

GET /api/v1/users/:login GET /api/v1/users/:login/repos

Read an exact profile or list its public repositories.

Search

GET /api/v1/search?type=&q=

Search repositories, users, code, commits, issues, or topics. Add page and per_page to paginate.

Labels

GET /api/v1/repos/:owner/:repo/labels

Read the labels attached to a repository.

MCP

POST /mcp

Streamable HTTP tools: get_user, list_user_repos, search_github, and list_repo_labels.

No app key. Send X-GitHub-Token if you need your own GitHub allowance or authenticated search. GitHub rate limits still apply. Setup and examples in the README ↗
